GDAL/PDAL 前処理

gdalwarp、pdal translate、ogr2ogr などを実行して入力を整形します。

Cesium Terrain（DEM → quantized-mesh）

Cesium Terrain Builder または tin-terrain を使用して DEM ラスターを Cesium 用 terrain タイルに変換します。

3D Tiles 1.1 後処理

3d-tiles-tools を使って 3D Tiles 1.0 を 1.1 GLB 化、または b3dm/i3dm から glb を取り出します。

BIM/CIM 前処理

IFC や CityJSON を glTF/GLB や CityGML/OBJ に変換します。変換後、mago-3d-tiler タブで 3D Tiles 化できます。

2D 画像タイル

gdal2tiles.py または ctb-tile を使って、衛星写真や航空写真を XYZ/TMS 形式の 2D 画像タイルに変換します。

glTF 最適化

gltf-pipeline を使って glTF/GLB を最適化（Draco 圧縮、KHR_texture_transform 追加など）します。

自動変換

入力パスを自動判別し、最適なコンバータを選択して変換します。

  • 出力形式を選ぶと表示されます
入力ディレクトリ内のファイルから自動判定します。
